# Real Estate Retainer Pack

## Included
- `content_library.md`: 60 LinkedIn posts, 30 X threads, and 10 short-form video scripts.
- `content_calendar.csv`: scheduling and review tracker.
- `generate_quote_graphic.py`: editable 1080x1080 quote graphic generator.
- `generate_market_chart.py`: precise dual-axis chart generator.
- `market_data.csv`: illustrative sample data only; replace it with approved current market data before publishing.

## Run
```bash
python3 generate_quote_graphic.py
python3 generate_market_chart.py
```

The scripts use deterministic rendering for exact typography and numeric charts. Review every claim, statistic, client reference, and local-market statement with the executive before publication.
